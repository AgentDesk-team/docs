## 2026-05-08 — historical update

The following entry describes an older onboarding flow. Sample Task 000 is retired and is not part of the current setup.

- Updated Getting Started into the corrected first-run onboarding flow:
  - Init Workspace.
  - Enter self-introduction/basic user information.
  - Open Dashboard and review Sample Task 000.
  - Create an agent, recommending the FE Dev role for Task 000.
  - Chat with the agent to assign Sample Task 000 and move it to Ready.
  - Explain that Ready means the task is eligible to be picked up for execution, not completed.
  - Wait for the agent to complete the task.
  - Open Files, publish/open the Task 000 form output link, then submit feedback or report an issue/bug.
- Updated the first-task page to match the corrected Sample Task 000 onboarding flow.
- Kept Team/developer reference docs internal and excluded from Mintlify publishing.
