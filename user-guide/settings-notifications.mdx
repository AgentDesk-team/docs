# Settings and notifications

Open **Settings** from the workspace rail or account menu. The available sections depend on the account, workspace role, plan, and deployment.

## Account and appearance

The current AgentDesk account panel exposes profile name/avatar, account email, and sign-out. Review the account shown before changing the profile. Use the email sign-in/reset flow for password recovery; legacy device, calendar integration, account-deletion, and password/email-change panels are not exposed as current hosted AgentDesk account controls.

Use **Appearance** for the supported language, theme, and presentation preferences. AgentDesk supports English and Vietnamese in its main UI. Keyboard Shortcuts lists the shortcuts available to the current app.

Some inherited or platform-specific settings panels are not available in the hosted web deployment. Use the controls actually offered rather than assuming every AFFiNE or LibreChat setting is an AgentDesk feature.

## Notifications

Open the notification control on the app rail to see permitted workspace events.

Filter **All**, **Unread**, **Task**, or **Comment**. Open an event to navigate to its related task or comment, and use the offered read controls to clear unread status.

A historical target can be unavailable because it was removed or you lost access. An old notification does not grant access to it.

Session unread badges in Agent Chat and notification unread counts are separate. Marking a session as read does not complete a task.

## Notification preferences

Use the Notification settings section for the preferences supported by your account. A configured preference does not prove a delivery channel is operational; check the available status and actual received event if delivery matters.
