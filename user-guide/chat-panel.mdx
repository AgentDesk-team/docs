# Chat Panel

The chat panel lets you talk to the selected agent while keeping the board visible.

## What you can send

- Text messages.
- File attachments.
- Pasted images.
- Clarifications or review notes.

## Best practices

- Select the right agent before sending.
- Include the task id when referring to existing work.
- Attach files when the agent needs exact source material.
- Ask the agent to create or update a task when the conversation becomes executable work.
- Ask for evidence when the agent claims completion.

## Attachments

Attachments should be delivered to the mapped agent session, not only displayed locally in chat. If an agent cannot see a file, resend it or attach it to the task/delivery area.

## Reviewing longer conversations

For longer work threads, the Chat Panel may let you load older messages instead of showing only the latest exchange.

Use the board and task detail together with chat when you need the full picture:

- chat for conversation,
- board for task state,
- artifacts/deliveries for proof and output.

## File links in chat

Some chat replies may include clickable workspace paths or output links.

Use them as shortcuts to:

- open a delivery,
- inspect a generated file,
- jump to proof or supporting material.

If the link looks important, still verify the related task state on the board before treating the work as complete.

## Chat is not enough

<Warning>
A chat answer is not the same as a completed task. For important work, check the board status and linked evidence or delivery files.
</Warning>
