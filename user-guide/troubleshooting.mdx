# Troubleshooting

## I do not see my workspace

Check whether you have initialized your workspace. New normal users may need to use **Init Workspace** before opening the dashboard.

## A task is not running

Possible reasons:

- The task is still in Inbox.
- The task is waiting for approval or clarification.
- The task is blocked.
- A dependency is not done yet.
- The intended agent is already active on another task.
- The agent session is unavailable.

Check the task status, next action, dependencies, and latest update.

## The wrong agent replied

Check which agent is selected in the chat panel. If the wrong agent was selected, switch to the right one and include the task id or summary for context.

## A file is missing

Check whether the file is an artifact or a delivery:

- Working proof usually belongs under artifacts.
- User-facing output belongs under delivery files.

If an attachment was only sent in chat, ask the agent to attach or copy it into the correct task/delivery location.

## The UI says work is done, but I am not sure

Ask for evidence. Good evidence may be a screenshot, test output, delivery file, or clear verification note.
