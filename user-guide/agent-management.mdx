# Agent Management

Agent Management lets you configure the AI teammates available inside your workspace.

## Role templates

Agents are created from approved role templates. A role template defines the agent's intended purpose, such as product assistant, backend developer, frontend developer, designer, QA, or DevOps.

<Warning>
An agent's role should not be casually changed after creation. If you need a different role, create a new agent from the correct template.
</Warning>

## Common actions

| Action | What it means |
| --- | --- |
| **Create agent** | Add a new agent from an approved role template. |
| **Edit display details** | Update display name or safe metadata. |
| **Disable agent** | Stop using an agent without permanently deleting its history. |
| **Review agent status** | Check whether the agent is enabled and routable. |

## Good agent setup

A useful agent should have:

- A clear role.
- A recognizable display name.
- A safe template/persona.
- Correct workspace context.
- A valid session/contact mapping.

## When to add a new agent

Add an agent when the work requires a stable role or repeated responsibility. Do not create a new agent for every small one-off request.
