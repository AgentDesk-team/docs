# Telegram integration status

The current React UI does not expose the legacy Dashboard's Telegram bot-binding dialog. Older instructions referring to a Telegram status chip and Connect Telegram button in Chat Panel should not be followed as steps for the current interface.

Telegram can still be part of a separately configured workspace runtime integration. Its availability and routing depend on that workspace's supported configuration and operator setup.

## If your workspace already uses Telegram

Confirm the intended bot and authorized account with your workspace administrator. Send a fresh message through the intended channel and verify both receipt and reply in that channel.

A connected bot identity or successful token validation is not proof that inbound messages are routed to the correct agent or that replies are delivered.

## If you need a new connection

Ask your workspace administrator to assess the supported integration for your current deployment. Do not paste a bot token into Agent Chat, Task Files, or public documentation.

This page preserves an existing documentation URL while distinguishing legacy instructions from current UI capabilities. Use [Agent Chat](/user-guide/chat-panel) for the current browser conversation workflow.
