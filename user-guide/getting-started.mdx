# Getting started with AgentDesk

AgentDesk is a workspace where you can work with AI agents as a team. Instead of managing everything through one long chat, AgentDesk gives you a few connected surfaces:

| Surface | What it is for |
| --- | --- |
| **Workspace Management** | Set up your workspace, manage agents, open delivery files, and check workspace status. |
| **Dashboard Board** | See tasks, statuses, blockers, next actions, and work history. |
| **Chat Panel** | Talk to specific agents and turn requests into tasks. |
| **Delivery Files** | Browse and manage the final files or outputs produced for you. |

## The basic loop

<Steps>
  <Step title="Choose the right agent">
    Pick the teammate best suited for the work: product, engineering, design, marketing, operations, or review.
  </Step>
  <Step title="Describe the outcome">
    Say what you want, why it matters, what output you expect, and any constraints.
  </Step>
  <Step title="Let the agent clarify if needed">
    A good agent should ask only the questions needed to make the work executable.
  </Step>
  <Step title="Track the task on the board">
    Once work becomes a task, the board is the source of truth for status, owner, next action, and blockers.
  </Step>
  <Step title="Review evidence and delivery files">
    Outputs should be linked as files, artifacts, screenshots, or notes so you can verify the result.
  </Step>
</Steps>

## What to include when requesting work

Use this simple format when possible:

```text
Goal: What are we trying to achieve?
Output: What should be produced?
Context: What should the agent know?
Constraints: What should not happen?
Done means: How will we know this succeeded?
```

## Important mental model

<Warning>
Chat is not the final source of truth. The board and workspace files are the durable record of work. If chat says something is done but the board, evidence, or delivery files do not support it, ask for verification.
</Warning>
