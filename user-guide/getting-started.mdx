# Getting started

## Sign in or create an account

Use the email sign-in flow, or an available Google or Facebook sign-in button. Social sign-in depends on the services enabled for your deployment.

For an email account, choose sign-up if you are new, complete any required email verification, and use **Forgot password** if you cannot sign in. Choose English or Vietnamese from the language selector. Signing into AgentDesk and connecting a model provider are separate steps.

## Complete onboarding

The first-run flow collects your profile, role, use cases, and workspace choice.

1. Enter the name you want agents and teammates to use.
2. Choose your role and intended uses.
3. Enter a workspace name and available workspace identifier, or review an invitation offered to your account.
4. Initialize the workspace and wait for setup to finish.
5. Continue into AgentDesk when the workspace is ready.

Initialization can take time while agents and the workspace runtime are prepared. If you reload, return to the saved onboarding step and current initialization status. If setup reports a retryable failure, use the displayed retry action.

The initial onboarding flow currently omits the outbound teammate-invitation step. Invite people later from **People**, subject to your plan and permissions.

## Take the product tour

The tour introduces Agent Chat, Agents, Sessions, Projects, Work Items, Files, available Wiki access, and Settings. You can continue, skip, or replay the tour using the available tour control. Skipping the tour does not remove your workspace.

Cherry, the AgentDesk assistant, can help you choose the next step. Ask a practical question such as:

```text
Help me organize a project for researching our next product launch.
Explain which agent I should use and what information you need.
```

No sample task is required to complete onboarding.

## Understand the workspace layout

| Area | Purpose |
| --- | --- |
| **Agent Chat** | Talk with a selected agent and revisit sessions. |
| **Projects** | Organize Work Items, planning, saved views, and project context. |
| **Files** | Browse shared workspace files, review outputs, sync selected folders, and publish supported apps. |
| **Workspace panel** | Open files, task previews, source changes, terminal, and application previews beside chat. |
| **Wiki** | Workspace knowledge, when included in your plan. |
| **Desktop** | The workspace's remote desktop surface, when available. |
| **Settings** | Account preferences and permitted workspace administration. |
| **Notifications** | Follow task activity and comments you can access. |

On narrow screens, open the navigation drawer to switch areas. The chat composer also groups some controls under **More composer controls**.

## Before your first request

Check the active workspace, agent, project binding, session visibility, and connected model. Upload source material or use context references when exact files or work items matter.

For tracked work, continue with [Create and review your first task](/user-guide/first-task). For a short direct request, describe the desired output and review the result in chat.
