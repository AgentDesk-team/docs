Skills now has detailed guides for the current workspace and agent browsers. Wiki and Desktop remain high-level overviews while their workflows evolve. Availability depends on the workspace's plan, permissions, and release.

## Skills

Skills provide reusable instructions and capabilities for agents. Workspace and agent skill surfaces help you understand what is available to the team or a particular agent.

An agent's role, context files, model connection, and skill set serve different purposes. A listed skill does not grant a missing tool, external-service credential, or additional permission.

Use [Workspace Skills](/user-guide/workspace-skills) for shared installation, editing, cloning, creation, and imports. Use [Agent skills](/user-guide/agent-skills) from the agent action menu for individual installations and workspace inheritance. See [Agent Context](/user-guide/agent-context) for persistent behavior and memory files.

## Wiki and project pages

Wiki is the workspace knowledge and document surface. Project Pages organizes project-related documents and knowledge where enabled.

Knowledge can support an agent's work when it is accessible and referenced appropriately. A document is distinct from a tracked work item, and document access still follows permissions.

Detailed authoring, organization, sharing, and knowledge-management procedures will be documented after the workflow settles.

## Desktop

Desktop provides access to the workspace's remote desktop environment when supported by the plan and runtime. It can support visual applications and browser-based work inside that environment.

The remote workspace Desktop is separate from your personal computer and from a file or application preview in the workspace panel.

Detailed connection, application, session, and operation procedures are deferred while this surface evolves.
