# FAQ

## Is AgentDesk just a chatbot?

No. AgentDesk includes chat, but the product is a workspace with tasks, agents, files, runtime state, and delivery outputs.

## Can I create work directly from chat?

Yes. A chat request can become a normal dashboard task. New tasks usually start in Inbox unless execution is explicitly approved.

## Can multiple agents work at the same time?

Yes, but each agent should have at most one active assignment at a time.

## Where should final outputs go?

Final user-facing outputs should go into Delivery Files. Internal proof and test evidence should go into artifacts.

## Can I edit files in Delivery Files?

Current scope supports read-only preview and file management operations. Editing file contents is not currently included.

## What should I do when a task is blocked?

Read the blocker and next action. A good blocker should explain what is missing and what you can do to unblock it.
