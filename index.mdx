AgentDesk brings AI agents, people, conversations, project work, and outputs into a shared workspace. Start in **Agent Chat**, organize tracked work in **Projects**, and review files and applications in **Files** or the workspace panel.

This guide follows the current React UI reviewed on **5 October 2026**. Available controls depend on your workspace plan, role, provider connections, and deployed release.

## Start with a complete workflow

1. [Sign in and set up your workspace](/user-guide/getting-started).
2. [Choose an agent](/user-guide/working-with-agents) and [start a session in the right scope](/user-guide/sessions-privacy).
3. [Create a project](/user-guide/projects) or use General for suitable existing work.
4. [Create, approve, and track a work item](/user-guide/first-task).
5. [Review the result and its evidence](/user-guide/task-detail), then accept it or request changes.

## Work, conversation, and evidence

A **session** holds a conversation with an agent. A **project** supplies a stable scope for related work and files. A **work item** tracks an outcome, its responsibility, and its lifecycle. A **delivery** is the result you review; **proof** shows how it was verified.

Chat can also handle direct requests without creating a tracked task. Ask explicitly for a work item when you need lifecycle tracking. Creating a task and approving its execution are separate actions.
