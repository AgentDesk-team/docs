# AgentDesk Documentation

AgentDesk is a workspace for working with a team of AI agents. It combines a task board, persistent team chat, workspace management, agent management, and delivery files in one place.

<Note>
This documentation is written for users and operators first. Team/developer context is included separately so new contributors can understand how to work safely with the current system.
</Note>

## What AgentDesk helps you do

- Brief work in plain language.
- Shape unclear requests into tasks with clear outcomes.
- Track work on a dashboard board.
- Talk to the right agent in a persistent chat panel.
- Review outputs and evidence in artifacts and delivery files.
- Keep each user workspace isolated from other users.
